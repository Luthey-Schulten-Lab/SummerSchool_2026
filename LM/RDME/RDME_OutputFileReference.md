# RDME Output File Reference #

Lattice Microbes RDME simulations produce a single **`.lm`** file per run. Despite the `.lm` extension the file is a standard **HDF5** file (format version 4) and can be opened with any HDF5-compatible tool (h5py, HDFView, etc.). A companion **`-jlmcache.h5`** file may also be generated by jLM during analysis; its structure is described separately at the end of this document.

## Opening the File

```python
import h5py
import numpy as np

f = h5py.File('MySimulation.lm', 'r')
```

---

## Top-Level Structure

```
MySimulation.lm
├── Model/
│   ├── Diffusion/
│   │   ├── DiffusionMatrix
│   │   ├── Lattice
│   │   ├── LatticeSites
│   │   └── ReactionLocationMatrix
│   ├── Reaction/
│   │   ├── DependencyMatrix
│   │   ├── InitialSpeciesCounts
│   │   ├── ReactionRateConstants
│   │   ├── ReactionTypes
│   │   └── StoichiometricMatrix
│   └── Spatial/
│       ├── Obstacles/
│       └── Regions/
├── Parameters/
│   ├── DiffusionParameterMatrix
│   ├── DiffusionParameterValues
│   ├── ReactionParameterMatrix
│   ├── ReactionParameterOrder
│   ├── ReactionParameterValues
│   └── SpeciesNames
└── Simulations/
    ├── 0000001/
    │   ├── Lattice/
    │   │   ├── 0000000000   (frame 0)
    │   │   ├── 0000000001   (frame 1)
    │   │   └── ...
    │   ├── LatticeTimes
    │   ├── SpeciesCountTimes
    │   └── SpeciesCounts
    └── 000000N/   (one group per replicate)
```

## `Parameters/` Datasets

### `SpeciesNames`
| Property | Value |
|----------|-------|
| Path | `Parameters/SpeciesNames` |
| Shape | `(n_species, 1)` |
| dtype | `object` (byte strings) |

Ordered list of species names. The index of each name corresponds to the column index in `SpeciesCounts` and the third axis of `DiffusionMatrix`. Species index 0 is conventionally reserved; user-defined species begin at index 1.

```python
names = f['Parameters/SpeciesNames'][:, 0]
# e.g. [b'gene', b'mRNA', b'P']
```

---

### `DiffusionParameterValues`
| Property | Value |
|----------|-------|
| Path | `Parameters/DiffusionParameterValues` |
| Shape | `(n_diff_params,)` |
| dtype | `float64` |

Unique diffusion coefficient values (m² s⁻¹) used in the simulation, indexed starting at 0. Index 0 always represents 0.0 (immobile). The `DiffusionParameterMatrix` maps source/destination site-type pairs and species to indices into this array.

```python
d_vals = f['Parameters/DiffusionParameterValues'][...]
# e.g. [0.0, 4.13e-14, 1.0e-13]
```

---

### `DiffusionParameterMatrix`
| Property | Value |
|----------|-------|
| Path | `Parameters/DiffusionParameterMatrix` |
| Shape | `(n_site_types, n_site_types, n_species)` |
| dtype | `int64` |

Each entry `[src, dst, species]` is an index into `DiffusionParameterValues`. Encodes which diffusion coefficient applies when a particle of `species` hops from a voxel of site type `src` to a voxel of site type `dst`. An index of 0 (D = 0) means diffusion across that transition is forbidden.

```python
d_matrix = f['Parameters/DiffusionParameterMatrix'][...]
```

---

### `ReactionParameterValues`
| Property | Value |
|----------|-------|
| Path | `Parameters/ReactionParameterValues` |
| Shape | `(n_reactions,)` |
| dtype | `float64` |

Rate constants for each reaction in the same order as the reaction indices used throughout the file. Units: s⁻¹ for first-order reactions; particle-based units for higher orders.

```python
k_vals = f['Parameters/ReactionParameterValues'][...]
```

---

## `Model/Reaction/` Datasets

The reaction datasets are identical in structure to those in the CME output file. See the [CME Output File Reference](../CME/CME_OutputFileReference.md) for full descriptions of:

- `InitialSpeciesCounts` — `(n_species,) uint32`
- `StoichiometricMatrix` — `(n_species, n_reactions) int32`
- `ReactionTypes` — `(n_reactions,) uint32` (1 = first-order, 2 = second-order)
- `ReactionRateConstants` — `(n_reactions, 10) float64`
- `DependencyMatrix` — `(n_species, n_reactions) uint32`

---

## `Model/Diffusion/` Datasets

### `LatticeSites`
| Property | Value |
|----------|-------|
| Path | `Model/Diffusion/LatticeSites` |
| Shape | `(Nx, Ny, Nz)` |
| dtype | `uint8` |

The geometry of the simulation volume. Each voxel is assigned an integer **site type** identifying its region. Site type 0 is the exterior (outside the simulated volume). User-defined regions are numbered sequentially from 1 onward in the order they were added during simulation setup.

```python
site_lattice = f['Model/Diffusion/LatticeSites'][...]
# e.g. unique types: {0: exterior, 1: cytosol, 2: shell, 3: nucleoid, ...}
```

---

### `Lattice` (initial particle placement)
| Property | Value |
|----------|-------|
| Path | `Model/Diffusion/Lattice` |
| Shape | `(Nx, Ny, Nz, n_particles_per_site)` |
| dtype | `uint32` |

The initial particle configuration of the simulation. Each entry stores the species ID of a particle occupying that slot in that voxel; 0 means the slot is empty. The MPD solver allows up to 16 particles per voxel by default.

---

### `DiffusionMatrix`
| Property | Value |
|----------|-------|
| Path | `Model/Diffusion/DiffusionMatrix` |
| Shape | `(n_site_types, n_site_types, n_species)` |
| dtype | `float64` |

The resolved diffusion coefficient (m² s⁻¹) for each combination of source site type, destination site type, and species. This is the expanded form of `DiffusionParameterMatrix` with actual coefficient values substituted in.

```python
D = f['Model/Diffusion/DiffusionMatrix'][...]
# D[src_type, dst_type, species_idx] = diffusion coefficient
```

---

### `ReactionLocationMatrix`
| Property | Value |
|----------|-------|
| Path | `Model/Diffusion/ReactionLocationMatrix` |
| Shape | `(n_reactions, n_site_types)` |
| dtype | `uint32` |

Boolean matrix (0 or 1). Entry `[reaction, site_type] = 1` means that reaction is allowed to fire in voxels of that site type. Reactions permitted in multiple regions will have multiple 1s across their row.

```python
rxn_loc = f['Model/Diffusion/ReactionLocationMatrix'][...]
```

---

## `Simulations/` — Per-Replicate Data

Replicates are stored as zero-padded 7-digit keys (`0000001`, `0000002`, …).

```python
reps = sorted(f['Simulations'].keys())
n_reps = len(reps)
```

---

### `LatticeTimes`
| Property | Value |
|----------|-------|
| Path | `Simulations/XXXXXXX/LatticeTimes` |
| Shape | `(n_frames,)` |
| dtype | `float64` |

Simulation time (seconds) at which each full lattice snapshot was written. The recording interval is set by the `latticeWriteInterval` parameter during simulation setup.

```python
lt = f['Simulations/0000001/LatticeTimes'][:]
```

---

### `Lattice/` (simulation frames)
| Property | Value |
|----------|-------|
| Path | `Simulations/XXXXXXX/Lattice/NNNNNNNNNN` |
| Shape | `(Nx, Ny, Nz, 16)` |
| dtype | `uint32` |

Each frame is stored as a zero-padded 10-digit key (`0000000000`, `0000000001`, …) and records the complete particle configuration at the corresponding time in `LatticeTimes`. Each entry is a species ID (0 = empty slot). The fourth axis has length 16, reflecting the MPD solver's maximum of 16 particles per voxel.

To count particles of a given species in a given region use `LMLattice.latticeStatsAll_h5fmt` (see [RDME_FunctionReference.md](./RDME_FunctionReference.md)) rather than indexing the raw array directly.

```python
frames = sorted(f['Simulations/0000001/Lattice'].keys())

# Read a single frame
frame_data = f[f'Simulations/0000001/Lattice/{frames[0]}'][...]
# shape: (64, 64, 64, 16), dtype uint32
```

---

### `SpeciesCountTimes`
| Property | Value |
|----------|-------|
| Path | `Simulations/XXXXXXX/SpeciesCountTimes` |
| Shape | `(n_timepoints,)` |
| dtype | `float64` |

Simulation time (seconds) corresponding to each row of `SpeciesCounts`. Recorded at the `speciesWriteInterval`, which is typically finer than `latticeWriteInterval`.

```python
ts = f['Simulations/0000001/SpeciesCountTimes'][:]
```

---

### `SpeciesCounts`
| Property | Value |
|----------|-------|
| Path | `Simulations/XXXXXXX/SpeciesCounts` |
| Shape | `(n_timepoints, n_species)` |
| dtype | `int32` |

Whole-system particle counts for every species at every recorded timepoint. This is the spatially-integrated trajectory — all voxels summed. Columns are ordered identically to `SpeciesNames`.

```python
counts   = f['Simulations/0000001/SpeciesCounts'][:]
mRNA_traj = counts[:, 1]
```

---

## Region-Specific Counts (Lattice Frames)

Because `SpeciesCounts` is spatially integrated, extracting region-specific trajectories requires iterating over lattice frames and using `LMLattice.latticeStatsAll_h5fmt`. See [RDME_FunctionReference.md](./RDME_FunctionReference.md) for the full pattern.

```python
import warnings
import jLM.LMFiles as LMLattice

site_lattice = f['Model/Diffusion/LatticeSites'][...]
rep_key      = sorted(f['Simulations'].keys())[0]
frames       = sorted(f[f'Simulations/{rep_key}/Lattice'].keys())

mRNA_idx  = 1   # from SpeciesNames order
cyto_idx  = 1   # site type for cytosol in LatticeSites

counts_cyto = np.zeros(len(frames), dtype=np.int64)
particle_lattice = None

with warnings.catch_warnings():
    warnings.simplefilter("ignore")
    for i, frame in enumerate(frames):
        if particle_lattice is not None:
            f[f'Simulations/{rep_key}/Lattice/{frame}'].read_direct(particle_lattice)
        else:
            particle_lattice = f[f'Simulations/{rep_key}/Lattice/{frame}'][...]
        pCount, _ = LMLattice.latticeStatsAll_h5fmt(particle_lattice, site_lattice)
        counts_cyto[i] = pCount[cyto_idx, mRNA_idx]
```

## jLM Cache File (`-jlmcache.h5`)

When jLM analysis functions are called on an RDME result file, jLM may create a companion file named `<basename>-jlmcache.h5` in the same directory. This file caches derived quantities (e.g. pre-computed region particle counts) to avoid re-reading the large lattice frames on repeated analysis calls. It is not produced by the solver itself and can be safely deleted if a fresh re-analysis is needed.

## Quick-Access Cheatsheet

```python
import h5py, numpy as np

f    = h5py.File('MySimulation.lm', 'r')
reps = sorted(f['Simulations'].keys())

# Metadata
names        = [n.decode() for n in f['Parameters/SpeciesNames'][:, 0]]
site_lattice = f['Model/Diffusion/LatticeSites'][...]   # (Nx, Ny, Nz) uint8
D            = f['Model/Diffusion/DiffusionMatrix'][...]

# Whole-system trajectory
ts     = f[f'Simulations/{reps[0]}/SpeciesCountTimes'][:]
counts = f[f'Simulations/{reps[0]}/SpeciesCounts'][:]   # (n_t, n_species)

# Lattice frames
frames = sorted(f[f'Simulations/{reps[0]}/Lattice'].keys())
lt     = f[f'Simulations/{reps[0]}/LatticeTimes'][:]    # (n_frames,)
frame0 = f[f'Simulations/{reps[0]}/Lattice/{frames[0]}'][...]  # (Nx, Ny, Nz, 16)

f.close()
```
